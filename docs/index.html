How it works

  1. Sense — 4× Grove EMG in headphone earmuffs (masseter + temporalis)
  2. Stream — ESP32-S3 at 1000 Hz → timestamp_ms,ch0,ch1,ch2,ch3
  3. Filter — 20–450 Hz Butterworth bandpass, 3 s windows
  4. Classify — 1D CNN → 10 silent commands
  5. Output — Companion app + text-to-speech
